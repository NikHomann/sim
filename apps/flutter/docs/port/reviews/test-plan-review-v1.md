## Proposed parity method
Per screen/theme/viewport: (1) layout boxes via parity ids (`data-parity` in React specs ↔ `Semantics(identifier:)` in Flutter; read via `flt-semantics-identifier` DOM attributes with `SemanticsBinding.instance.ensureSemantics()` under the e2e define, or `tester.getRect(find.bySemanticsIdentifier)` + a `ParityProbe` reporting resolved tokens through `binding.reportData`): rect delta ≤1px, token values exact, text equal, child count equal; (2) colour sampling at spec anchor points in non-text zones, ΔE76 ≤ 2; (3) SSIM ≥ 0.98 on masked non-text regions; (4) per-component goldens from measured CSS (`generated/css-measurements.json` recorded from real React screens; `sim_design` tests assert `SimTokens` against it). Report `parity/<screen>.json` + HTML diff page.

## CI shape
Gate: `flutter pub get` → `dart format --set-exit-if-changed .` → `flutter analyze` → `dart run tools/check_generated.dart` → `dart run tools/check_parity_docs.dart` → `dart run tools/check_licenses.dart` → `flutter test --test-randomize-ordering-seed random --exclude-tags contract,e2e` → upload failures.
Nightly: compose up with overlay (`POSTGRES_DB=simstudio_test`, `TRUSTED_ORIGINS`, Mailpit, `TZ=UTC`) → `dart run tools/seed/seed.dart --out seed.json` → `flutter build web --base-href /app/ --profile` → `node tools/dev_proxy.mjs --static build/web` → contract tests → chromedriver → `flutter drive ... -d web-server --profile --web-launch-url http://localhost:3001/app/` per suite → `node tools/parity/capture.mjs && compare.mjs` → Windows `flutter test integration_test -d windows` → collect compose logs → upload reports always.
Report schema: `{ suite, startedAt, completedAt, status, transport, baseUrl, upstreamCommit, flutterVersion, seed:{userId, workspaceId, workflowIds[]}, requestCount, checks:[{name, status, durationMs, error?, screenshot?, artifacts?}], httpErrors:[{method,path,status}], socketEvents?:[{event,count}], frameStats?:{avgMs,p95Ms,jank}, parity?:[{screen, theme, viewport, layout:{pass,maxDelta,failures[]}, colors:{pass,maxDeltaE}, ssim:{value,pass}, networkDiff:{missing[],extra[]}}] }`.
