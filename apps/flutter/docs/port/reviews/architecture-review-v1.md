# Review of 00-plan.md draft v1: Flutter architecture and feasibility (agent, 2026-10-21)

1. BLOCKER: fonts. `apps/sim/app/_styles/fonts/season/` has only `SeasonSansUprightsVF.woff2` (weight 300–800). Flutter loads TTF/OTF, not WOFF2; `FontWeight` does not drive a variable font's `wght` axis (flutter/flutter#33709) → every text style needs `fontVariations: [FontVariation('wght', n)]`. No Season license file in repo (`public/brand/fonts` also has commercial `Soehne-Kraftig.ttf`). Change: extraction decompresses WOFF2→TTF; `SimTokens` styles use `FontVariation`; license check becomes an open question.
2. BLOCKER: dev loop. `flutter run` has no `--base-href` (only `flutter build web`); `-d web-server` serves at `/`, so the proxy must strip `/app`, `web/index.html` must hard-code `<base href="/app/">`, DWDS endpoints (`/$dwds*`) are origin-rooted, SSE must be unbuffered; hot reload disabled for web-server (hot restart only). Simpler fallback: `flutter run -d chrome --web-port 8087 --web-launch-url http://localhost:3001/app/` (hot restart via Chrome debug protocol, never crosses the proxy). Make it a Phase 0 spike.
3. MAJOR: toolchain age. Flutter 3.38.9 (2026-01-28); `desktop_drop` 0.9.x needs Dart ≥3.13 (0.8.4 resolves on 3.10); other packages will follow. Record channel/version in `docs/port/TOOLCHAIN.md`, pin every package, or upgrade stable first.
4. MAJOR: Patrol: no Windows; web served from Patrol's own origin → cookies/origin/CORS fail. Windows = `flutter test integration_test -d windows`; web = plain Playwright or `flutter drive` through the proxy.
5. MAJOR: desktop auth: reuse the existing desktop handoff (`apps/sim/app/api/desktop/auth/handoff/route.ts`, `lib/auth/desktop-handoff.ts`: one-time token redeemed via `/api/auth/one-time-token/verify` into a separate desktop session, 3-min TTL, loopback port validated by `app/desktop/auth/validation.ts`). Phase 6 = system browser → `/desktop/auth?...` → loopback (OttoFrontend has `localhost_auth_server.dart`, RFC 8252) → redeem into cookie jar. Direct `sign-in/email` optional fast path; "no Origin header passes" unverified → L4 contract test.
6. MAJOR: `fetch_client` is web-only and an `http.Client`, not a Dio adapter. OttoFrontend has `lib/infrastructure/api/web_streaming/fetch_stream_adapter_web.dart`: a `HttpClientAdapter` on `package:web` fetch with `ReadableStream`, `AbortController`, credentials, plus a `dart:io` stub. Port it into `sim_api` (conditional import). Dio's XHR adapter does not stream.
7. MAJOR: `socket_io_client` 3.1.6: server 4.8.4 compatible; `OptionBuilder.setAuthFn` exists; but native builds are websocket-only (`setTransports(['websocket'])`); Manager cache ignores `dispose()` → `enableForceNew()` when re-creating.
8. MAJOR: canvas pitfalls: (a) `RenderBox.hitTest` rejects points outside the box → nodes outside the Stack's size are unclickable; custom render object or Stack sized to content bounds with origin offset. (b) `CustomPainter.hitTest` must be implemented; edge picking samples `PathMetrics` at hit width 30 in canvas units (`Path.contains` is fill-only). (c) `RenderTransform` without a layer re-rasterises all nodes per pan frame → `RepaintBoundary` per node, raster-cache during gestures (`filterQuality` non-null), crisp at rest. Phase 0 spike: 200 synthetic nodes, measure pan fps on CanvasKit and Windows.
9. MAJOR: state leaks on 200-block path. React uses per-block selectors (`workflow-block.tsx:751`, `useSubBlockValue` with `isEqual`), node objects recreated only on structural hash (`workflow.tsx:2836-2849`), drag positions local. Change: per-block `BlocSelector`/`context.select` with identity-stable sub-objects; live drag positions in per-node `ValueNotifier`s committed at drag end; subblock values keyed `(workflowId, blockId, subblockId)`; persistent maps (`fast_immutable_collections`), no deep `Equatable` on the block map.
10. MAJOR: persistence. Console entries persisted to IndexedDB every 5s uncapped (`stores/terminal/console/storage.ts`); `shared_preferences` (5 MB, `flutter.` key prefix) wrong; `sidebar_collapsed` is a cookie. Change: `KeyValueStore` abstraction with IndexedDB (`package:web`) on web, file/sqlite on Windows; React-shared keys read via `package:web` localStorage / `document.cookie`.
11. MAJOR: nuqs → go_router: go_router rebuilds the page on every query change, no throttled replace. `UrlStateCubit` per page owning filters, throttled `router.replace`; pages derive from the cubit. `usePathUrlStrategy` honors `<base href="/app/">`; routes declared without the `/app` prefix.
12. MAJOR: layering. `sim_design` "Flutter only" contradicts re_editor/fl_chart/flutter_svg/gpt_markdown → "no sim_* deps". Operation queue/undo (sim_workflow) needs the realtime vocabulary (sim_api) → cycle: port `packages/realtime-protocol` into `sim_workflow` (or `sim_protocol`) with abstract transport; `sim_api` implements the socket transport. One directory per subblock type under `features/workflows/editor/subblocks/<type>/`.
13. MAJOR: Phase 0 missing: `Query<T>`, fetch stream adapter, `KeyValueStore`, `FontVariation` styles, icon precompilation (`vector_graphics_compiler` → `.vec`), `web/index.html` base href + `flutter_bootstrap.js`, DWDS/proxy spike, canvas spike, reference-token tokenizer (short-input renders tokens in Phase 2). Phase 3 larger than Phase 2. Effort: P0 12%, P1 10%, P2 20%, P3 25%, P4 20%, P5 8%, P6 5%.
14. MINOR: icons: `flutter_svg` `currentColor` via `SvgTheme(currentColor:)`; `components/icons.tsx` has 210 gradient refs, 1 `<filter>` (unsupported), 1 `<mask>`, 16 raster `<image>`. Run `vector_graphics_compiler` in extraction, PNG@2x fallback on failure.
15. MINOR: `re_highlight` 0.0.3 (highlight.js 11.9) has js/ts/python/json/sql; `re_editor` 0.10.0 maintained; per-field undo persisted in React (`stores/undo-redo/code/storage.ts`), re_editor undo in-memory → known gap or custom controller.
16. MINOR: `xterm` 4.0.0 (2024-02) verify compiles; `window_manager` 0.5.2 fine; `super_clipboard` only when image/HTML paste needed (Rust prebuilts); `dio_cookie_manager`/`cookie_jar` no web → `dart:io` conditional; `flutter_secure_storage` desktop only; gpt_markdown, two_dimensional_scrollables, desktop_drop, alchemist fit.
17. MINOR: runtime config scrape: `/login` redirects to `/home` when a cookie exists; promote `GET /api/public-env` to a required Phase 0 addition.
18. MINOR: skwasm needs `--wasm` + COOP/COEP headers on `/app/*` (Next sets `unsafe-none`, `next.config.ts:320-332`); default CanvasKit.
19. Risks not listed: CSP for `/app` (CanvasKit needs `wasm-unsafe-eval`, `connect-src` socket origin); bundle weight 4–6 MB; browser-reserved shortcuts (Mod+L, Mod+K) need `preventDefault` via handled `KeyEvent`s; Flutter web semantics off by default (`SemanticsBinding.ensureSemantics`); downloads via `package:web` anchor; upstream churn with no re-baseline cadence; realtime socket also carries Yjs file-doc rooms (tolerate unknown events); Windows packaging needs signing cert + ATL.

Verified correct: trustedOrigins (`auth.ts:212,291-295`), cookie defaults, `TRUSTED_ORIGINS=http://localhost:3001` right knob; proxy.ts CORS fallback 3001, execute wildcard, `isCrossSiteSessionRequest`; realtime CORS (`apps/realtime/src/config/socket.ts`); socket auth callback (`socket-provider.tsx:467-480`); `publicEnvHtmlAttributes()`; package platform claims; design numbers; orchestration rules.
