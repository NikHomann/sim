# Generated icons

The emcn UI set (192 icons, `packages/emcn/src/icons/*.tsx`) is generated by
`tool/generate_emcn_icons.dart` into `lib/src/icons/sim_emcn_icons.g.dart`
(`SimEmcnIcons`), with assets in `assets/icons/emcn/` (`.svg` + precompiled
`.vec`). Re-run it after `tools/gen` refreshes `generated/icons/`:

    dart run tool/generate_emcn_icons.dart

Icons that overlap the hand-ported `SimIcons` set (`assets/icons/*.svg`) are
aliased to those constants and not copied twice.

The brand set (~370 icons, `apps/sim/components/icons.tsx`) is not part of
this package yet; when it is, its generated Dart goes in this directory, which
is excluded from analysis (`analysis_options.yaml`).
